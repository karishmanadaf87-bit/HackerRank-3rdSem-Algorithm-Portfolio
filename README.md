## About

This repository contains my solutions to five algorithmic problems completed as part of my 3rd semester HackerRank Algorithm Portfolio activity. The solutions are implemented in Java and focus on arrays, sorting, searching, and greedy techniques.

## Problems Completed

| No. | Problem | Technique | Time | Space |
|---|---|---|---|---|
| 1 | Mini-Max Sum | Min/Max Tracking | O(N) | O(1) |
| 2 | Birthday Cake Candles | Maximum + Counting | O(N) | O(1) |
| 3 | Insertion Sort Part 1 | Insertion Sort | O(N) | O(1) |
| 4 | Binary Search | Divide and Conquer | O(log N) | O(1) |
| 5 | Mark and Toys | Sorting + Greedy | O(N log N) | O(1) |

## Approaches

### 1. Mini-Max Sum
Calculated the total sum while tracking the minimum and maximum values. The minimum sum is obtained by excluding the maximum value, and the maximum sum by excluding the minimum value.

### 2. Birthday Cake Candles
Found the maximum candle height and counted how many candles have that height.

### 3. Insertion Sort Part 1
Stored the last element and shifted larger elements to the right until the correct position was found.

### 4. Binary Search
Used two pointers, `low` and `high`, to repeatedly divide the sorted array and locate the target element.

### 5. Mark and Toys
Sorted the prices and purchased the cheapest toys first while staying within the available budget.
